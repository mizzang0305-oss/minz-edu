# Learning System

## 첫 개념

```text
수 가르기와 모으기 → 10 만들기 → 받아올림이 있는 덧셈 → 여러 풀이 방법
```

대표 조작은 `8 + 7`이다. 7개 블록 중 2개를 8의 10칸 틀로 옮기면 `10 + 5 = 15`가 눈에 보인다. 설명은 “8에 2를 더하면 10이 돼. 7에서 2를 옮기면 5가 남아.” 두 문장 이내로 제한한다.

## 콘텐츠

typed data로 다음 23개 미션을 제공한다.

| 유형 | 수량 | 역할 |
| --- | ---: | --- |
| 10 만들기 관찰 | 5 | 빈칸 구조 발견 |
| 블록 옮기기 | 5 | 직접 조작 |
| 받아올림 계산 | 5 | 10 묶음 적용 |
| 문장 상황 | 3 | 다른 맥락 적용 |
| 이유 설명 | 3 | 개념 언어화 |
| 심화 | 2 | 여러 방법 발견 |

## 난이도 신호

최근 성공 수뿐 아니라 힌트 횟수, 조작 어려움, 응용 성공, 중단 신호를 함께 본다. 5개 중 4개 성공·힌트 1회 이하·응용 성공이면 다음 변형을 열고, 조작 어려움 3회·3단계 힌트·중단 신호가 있으면 같은 개념을 더 구체적인 그림으로 바꾼다. 아이 화면에는 단계 하향을 노출하지 않는다.

## 협동 개별화와 공정성

- 각 플레이어의 `levelProfile`에 맞는 task를 배정하되 공격력은 학년과 직접 비례하지 않는다.
- 민표에게는 블록 조작, 친구에게는 남은 수 선택처럼 역할을 다르게 준다.
- 난이도 대신 `번개 암호`, `불꽃 암호`라고 표시한다.
- 답을 대신 알려주는 행동은 링크 보상이 아니며, 설명·힌트·기다림은 협동 행동으로 기록한다.

## 개념 상태

보호자 화면만 `발견 중 → 익히는 중 → 자유롭게 사용`을 보여준다. 아이 화면에는 수치·순위·정답률을 표시하지 않는다.
