# MVP Scope

## 구현 범위

- Next.js 16 App Router, TypeScript strict, Tailwind CSS 4, Phaser 3.90.
- 홈, 보호자 설정, 모험 지도, 숫자 숲 전투, 결과, 보물 가방, 보호자 화면.
- 1인 모드와 같은 기기 2인 협동을 같은 다중 플레이어 모델로 처리.
- HP, 보호막, 개인 전투/개념 게이지, 팀 링크, 보스 HP/보호막.
- 10칸 틀 블록 이동, 남은 수 선택, 문장 상황, 두 풀이 방법.
- Phaser 도형 캐릭터 1~2명, 슬라임, 공격, 데미지, 흔들림, 스페셜 컷신.
- 5초 내 양쪽 준비 입력과 합동 필살기.
- 개인/팀 보상, 모험 이력, 생각 기록의 localStorage 저장.
- 온라인 방 상태·이벤트 타입과 권한 서버 설계 문서.
- 협력 행동 자동 기록과 보호자용 2인 UX 관찰지.
- localStorage v1 기록을 보존하는 v2 마이그레이션.
- Vitest/RTL/Playwright 검증 기반.

## 의도적으로 제외

- 실제 온라인 방과 서버, Supabase, 외부 DB, 회원가입.
- 공개 채팅, 자유 텍스트 채팅, 음성 채팅, 랜덤 매칭, PvP, 경쟁 랭킹.
- 광고, 결제, 확률형 보상, 외부 AI API.
- 정식 이미지/음원 에셋. 효과음과 짧은 낭독은 브라우저 Web Audio/SpeechSynthesis로 제공하며 브라우저별 음색 차이는 후속 검증한다.

## 완료 판정 시나리오

### 1인

`민표 설정 → 숫자 숲 → 8+7 블록 2개 이동 → 번개 공격 → 15 선택 → 두 방법 선택 → 민즈 썬더 드래곤 브레이크 → 보상/생각 저장 → 새로고침 유지`

### 2인

`친구 추가/캐릭터 → 두 캐릭터 등장 → 민표 블록 조작 → 민표 공격 → 친구 남은 수 선택 → 친구 공격 → 팀 링크 100 → 협동 심화 → 양쪽 준비 → 민즈 트윈 드래곤 브레이크 → 개인/팀 보상 → 협동 이력 저장`

## 후속 한 단계

실제 아동 2명이 같은 태블릿에서 5~10분 협동 세션을 수행하는 관찰 테스트를 진행해 차례 인지, 기다림 시간, 도움 행동, 합동 스킬 만족도를 검증한다. 온라인 방 구현은 이 UX 검증 이후 별도 승인 범위로 진행한다.
