# 같은 기기 2인 협동 UX 관찰 프로토콜

## 목적

실제 아동 2명이 태블릿 또는 PC 한 대에서 5~10분 협동 모험을 진행할 때 다음 네 가지를 확인한다.

1. 누구 차례인지 스스로 알아차리는가.
2. 상대의 차례를 불편하지 않게 기다리는가.
3. 정답을 대신 누르지 않고 설명·힌트·응원 행동이 발생하는가.
4. 합동 필살기가 다시 참여하고 싶은 동기를 만드는가.

이 관찰은 성적, 정답률, 속도, 아이 간 우열을 평가하지 않는다.

## 준비

- 기기 1대, 의자 2개, 보호자 또는 관찰자 1명
- `/setup`에서 `친구와 같은 화면` 선택
- 두 아이가 직접 이름과 캐릭터를 고르게 함
- 알림을 끄고 10분 동안 방해받지 않는 장소 준비
- 사진·영상·음성 녹화는 별도 동의 없이는 하지 않음
- 메모에 성명, 연락처, 학교 등 개인정보를 적지 않음

## 관찰 진행

### 시작 전 30초

관찰자는 다음 문장만 안내한다.

> 둘이 같은 숫자 보스를 막는 모험이야. 화면이 알려주는 차례대로 해보고, 서로 도와도 좋아.

조작 방법과 답을 먼저 설명하지 않는다.

### 플레이 중

관찰자는 개입을 최소화하고 다음 행동만 짧게 메모한다.

- 차례 표시를 본 뒤 스스로 손을 바꾸는 순간
- 상대 화면을 대신 누르려는 순간
- 기다리는 동안 딴짓, 불만, 재촉이 생기는 순간
- 그림 힌트, 한 단계 나누기, 응원을 선택하는 순간
- 자기 방법을 말하거나 상대 설명을 듣는 순간
- 합동 준비 버튼을 맞춰 누를 때의 표정과 발화
- 아이가 먼저 다시 하자고 말하는지

아이 한 명이 불편함, 울음, 중단 의사를 보이면 즉시 멈추고 보상과 기록을 유지한다.

### 종료 직후 2분

아이에게 점수를 묻지 않는다. 다음 두 질문만 사용할 수 있다.

1. 오늘 둘이 같이 한 것 중 무엇이 가장 재미있었어?
2. 다음에는 어떤 작전이 있으면 좋겠어?

그 뒤 보호자가 `/parent/observation`에서 관찰지를 저장한다.

## 통과 기준

첫 세션은 다음을 모두 만족하면 `협동 UX 1차 통과`로 본다.

- 두 아이 모두 최소 한 번 자기 역할을 직접 수행함
- 차례 인지 평점 3 이상
- 기다림 편안함 평점 3 이상
- 설명·힌트·응원 행동이 조금이라도 관찰됨
- 합동 필살기 만족도 4 이상
- 한 아이가 모든 입력을 독점하지 않음
- 울음·비난·팀 보상 손실 경험이 없음

통과하지 못하면 온라인 기능으로 확장하지 않고 같은 기기 UX를 먼저 수정한다.

## 자동 기록 해석

게임은 `함께 완료`, `도움 단서`, `설명 공유`, `재도전`, `합동 스킬`, `차례 전환`만 자동 저장한다. 이 값은 행동 횟수이며 품질이나 성적이 아니다. 자동 기록은 보호자 관찰을 대체하지 않는다.

## 다음 의사결정

최소 3회 세션에서 동일한 불편이 반복될 때만 UI 구조를 변경한다. 단 한 번의 주관적 반응만으로 난이도나 공격력 차이를 만들지 않는다.
