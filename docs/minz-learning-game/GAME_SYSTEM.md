# Game System

## 상태와 책임

`CombatSystem`의 순수 reducer만 전투 상태를 변경한다. React는 입력을 action으로 전달하고 HUD를 렌더링한다. Phaser는 상태를 확정하지 않고 이벤트 브리지를 통해 받은 상태와 연출만 표현한다.

```text
INTRO → PLAYER_MANIPULATE → PLAYER_ANSWER → SPECIAL_CHALLENGE
→ SPECIAL_READY → SPECIAL_CUTSCENE → RESULT
```

## 전투 수치

| 항목 | 1인 | 2인 |
| --- | ---: | ---: |
| 플레이어 HP / 보호막 | 100 / 25 | 각 100 / 25 |
| 보스 HP / 보호막 | 120 / 30 | 250 / 50 |
| 개인 전투·개념 게이지 | 분리 | 플레이어별 분리 |
| 팀 링크 | 사용 안 함 | 공유, 최대 100 |

게이지는 `SkillGaugeSystem`, HP·보호막은 `DamageSystem`, 보상은 `RewardSystem`에서 계산한다. 모든 값은 0~100 또는 0~최대 HP 범위로 제한한다.

## 타격감

- 강한 공격: 캐릭터 전진, 속성 이펙트, 슬라임 흰색 플래시, 화면 흔들림, 데미지 숫자.
- 스페셜: 배경 암전, 양쪽 컷인, 스킬명, 속성 결합, 다단 궤적, 대폭발, 보스 소멸.
- 정식 에셋 없이 Phaser Graphics와 도형을 사용하며 교체 가능한 Scene 경계로 둔다.

## 2인 턴과 합동 입력

1. 플레이어 1이 7 블록 중 2개를 8의 빈칸으로 옮긴다.
2. 플레이어 1 공격 뒤 `activePlayerIndex`가 플레이어 2로 이동한다.
3. 플레이어 2가 남은 수 5를 찾고 공격한다.
4. 둘이 서로 다른 풀이 방법이 같은 15가 되는 작전을 고른다.
5. 팀 링크 100, 각 개인 게이지 70 이상이 되면 합동 스킬을 연다.
6. 양쪽 준비 버튼을 5초 안에 모두 누르면 `민즈 트윈 드래곤 브레이크`가 발동한다.
7. 한쪽만 누르고 시간이 지나면 준비 상태만 초기화하고 반복을 허용한다.

## 어려움 처리

- 1회: 보스가 공격을 막고 다른 작전을 권한다. HP 손실 없음.
- 2회 이후: 보호막만 5 감소하고 개별 힌트를 제공한다.
- 재도전과 힌트 사용 횟수는 기록하지만 아이 화면에 점수로 표시하지 않는다.
- 협동 링크는 어려움이 생겨도 깎이지 않는다.
