# 화면 안 상호작용 흐름

## 목적

이동 화면, 상호작용 버튼, 문제 풀이 화면이 서로 떨어져 보이지 않도록 Roblox형 근접 상호작용 구조를 사용한다.

## 탐험 흐름

1. 방향키·WASD·화면 조이스틱으로 이동한다.
2. NPC, 보물 상자, 숨은 통로, 보스에 가까워지면 대상 바로 위에 행동 버튼이 나타난다.
3. 화면 버튼을 누르거나 `E`·`Enter` 키로 실행한다.
4. 숨은 통로는 지나가기만 해서는 열리지 않고 직접 조사해야 한다.
5. 탐험 조건을 완료한 뒤 보스 버튼을 누르면 별도 시작 화면 없이 전투로 전환된다.

## 전투 흐름

- 데스크톱은 전투 장면과 문제 패널을 좌우로 동시에 표시한다.
- 휴대폰·태블릿은 위쪽 47%에 전투 장면, 아래쪽 53%에 문제 선택을 고정한다.
- 페이지 자체는 스크롤하지 않고 문제 패널 내부만 필요한 경우 스크롤한다.
- 모바일에서는 전체 전투 상태 패널 대신 HP·방어·보스 HP를 전투 장면 아래의 압축 HUD에 표시한다.

## 접근성

- 화면 상호작용 버튼은 실제 HTML `button`으로 제공한다.
- 키보드 `E`와 `Enter`를 지원한다.
- 이동 버튼은 실제 표시 크기 44px 이상을 유지한다.
- `prefers-reduced-motion`에서는 상호작용 버튼의 반복 애니메이션을 끈다.

## 검증 기준

- NPC·상자·숨은 길·보스 이벤트가 게임 캔버스 안에서 클릭 가능
- 전투 장면과 답 선택 영역이 동일한 모바일 뷰포트 안에 표시
- iPhone SE, iPhone 16 Pro, Galaxy S24, Fold, Galaxy Tab 안전 영역 통과
- 터치 취소 후 이동 입력 고착 없음
