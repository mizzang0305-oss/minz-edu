# 교육과정 기반 주별 모험 경로

## 목적

아이에게 학년 전체 내용을 처음부터 강제하지 않고 `학년 → 학기 → 주차 → 학습 목표`를 고르게 한다. 이미 아는 목표는 짧은 진단을 통과하면 게임 안에서 준비된 것으로 표시하고 다음 목표로 이동한다.

## 정확성 경계

- 국가 교육과정은 성취기준을 제시하지만 전국 학교의 공통 주별 진도표를 정하지 않는다.
- 앱의 과목별 8주 경로는 공식 주차표가 아니라 **교육과정 기반 민즈 추천 경로**다.
- 실제 진도는 학교, 교과서, 행사와 재량 운영에 따라 달라질 수 있으므로 보호자와 학생이 시작 주차를 변경할 수 있다.
- 유아는 2019 개정 누리과정의 유아·놀이 중심 공통 과정을 따른다. 앱의 5·6·7세 수 범위는 공식 연령별 성취기준이 아니라 게임 난이도 조정이다.
- 제품 지원 범위는 유아 5~7세, 초등 1~6학년, 중등 1~3학년이다. 중등 문항은 수학·영어 영역별 대표 세트이며 교과서 전체 범위를 대체하지 않는다.
- 중등 문항은 현재 `pending-teacher-review` 상태다. 실제 교사 이름과 검수 일시가 기록되기 전에는 교사 승인 콘텐츠라고 표시하지 않는다.

## 과목별 시작 주차와 8주 구조

| 과목 | 시작 주차 | 제공 주차 | 연결 월드 |
|---|---|---|
| 수학·유아수학 | 8주차 | 8~15주차 | 숫자 숲 |
| 국어·유아 언어 | 9주차 | 9~16주차 | 단어섬·이야기 성 |
| 영어 | 10주차 | 10~17주차 | 단어섬 |

각 과목은 `새 원리 발견 → 기술 훈련 → 모험 적용 → 수호자 도전` 4주 묶음을 두 번 진행한다. 수학과 국어는 독립 경로이므로 9~15주차에는 두 과목 목표가 함께 존재하며, 과목 탭에서 나누어 볼 수 있다. 유아수학은 세기·수 모으기·규칙·비교를 손으로 조작하는 숫자 숲 활동으로 제공한다.

## 진단과 건너뛰기

- 유아·초등 진단은 3문항 MVP이며, 중등 목표는 영역별 6문항 은행을 사용한다. 모두 첫 시도에 해결하면 `게임 내 준비됨`으로 표시한다.
- 이 표시는 학교 성취도나 공식 숙달 판정이 아니다.
- 진단에서 막히면 같은 목표의 훈련장으로 이동한다.
- 결과 화면은 등급이나 친구 비교 대신 첫 시도 해결, 재시도, 힌트 사용과 끝까지 해결한 행동을 보여준다.
- 1회 플레이는 `오늘의 관찰`, 2회 또는 6문항 이상부터 `학습 경향`으로 표시한다.

## 아동 데이터 최소화

- 저장: 목표 ID, 문항 수, 첫 시도 해결 수, 재시도 수, 힌트 수, 완료 시각, 익명 오답 유형 태그별 횟수.
- 저장하지 않음: 선택한 오답 원문, 반응 시간, 자유서술 진단값, 친구와의 순위.
- 현재 학습/훈련 기록은 브라우저 localStorage v6에 먼저 저장되며, 보호자 Google 계정이 연결되면 허용된 집계 기록만 동기화한다.
