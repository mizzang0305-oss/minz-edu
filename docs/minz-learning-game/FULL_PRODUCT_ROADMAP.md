# 민즈 AI 공부게임 최종 완성 로드맵

## 결론

최종 제품은 `로블록스처럼 직접 움직이는 안전한 학습 RPG`를 목표로 한다. 아이는 맵을 탐험하고 친구와 퀘스트를 수행하며, 학습 문제는 문을 열거나 보스를 공략하는 실제 게임 행동으로 연결된다.

핵심 학습·협동·인벤토리는 영구 무료 기능으로 유지한다. 구독·결제·광고·확률형 보상은 이 로드맵에 포함하지 않는다. 향후 후원을 열더라도 보호자가 선택하는 별도 후원 창구로만 운영하고, 후원 여부가 아이의 학습 접근·진행·보상에 영향을 주지 않게 한다.

## 현재 완료 상태

- 유아 5~7세, 초등 1~6학년 프로필
- 단계별 수학 문제와 힌트
- Phaser 기반 직접 이동, 숫자 조각 수집, 친구 자동 동행, 보스 포털
- CC0 Open Duelyst 캐릭터·보스와 CC0 Ninja Adventure 통합 지형 자산
- 숫자 숲·단어섬·이야기 성의 32px 정수 배율 Tiled 실제 레이어 렌더링
- 전투 장면과 문제가 한 화면에 유지되는 반응형 전투 콕핏
- Google 보호자 계정 기반과 온라인 방 기초
- 결과·보상·인벤토리·보호자 기록
- PC·태블릿·휴대폰 반응형 E2E
- Stage ID 기반 진행 저장과 주별 목표·훈련 기록 v5
- 연령·학년·학기별 수학 8주차·국어 9주차 시작 목표와 `게임 내 준비됨` 진단 건너뛰기
- 결과·보호자 화면의 강점/다음 연습 관찰 카드와 독립 훈련장

## 오케스트라 작업 구조

| 작업단 | 책임 |
|---|---|
| 게임 월드 | Phaser 맵, 이동, 충돌, NPC, 퀘스트, 연출 |
| 학습 콘텐츠 | 유아수학·유아 언어·초등 국어·수학·독해 데이터 |
| 온라인 | Google 계정, 친구 방, 재접속, 저빈도 게임 이벤트 동기화 |
| 보호자·안전 | 자녀 프로필, 리포트, 개인정보 최소화, 접근성 |
| QA·성능 | 실제 기기, 저속망, 메모리, FPS, 회전, 입력 복구 |
| 자산·라이선스 | CC0/상업 사용 가능 자산 선별, 출처·라이선스 감사 |

각 작업단은 서로 다른 파일 경계를 사용하고, 통합 단계에서 전체 E2E를 통과해야 다음 Phase로 간다.

## Phase 1 — RPG 기반 안정화

안정화 기준을 통과했다. 추가 실기기 장시간 성능 검증은 Phase 9에서 반복한다.

- 맵 데이터를 Scene 밖으로 분리
- Ninja Adventure CC0 타일셋으로 세 월드 화풍 통일
- 바위·나무·강 충돌
- 통과 가능한 다리
- 선택형 숨은 길
- 프레임 독립 이동 속도
- 터치 고착·백그라운드 입력 해제
- reduced-motion과 Phaser 객체 정리
- Stage ID 기반 정확한 해금

완료 기준:

- Stage 1 반복 플레이로 Stage 3가 열리지 않음
- PC·태블릿·휴대폰에서 같은 시간 이동 거리가 유사함
- 방향키·WASD·터치로 수집→다리→포털 완주
- 화면 전환 후 Phaser canvas와 이벤트가 남지 않음

## Phase 2 — 숫자 숲 완성

현재 상태: **핵심 완료**. NPC 대화, 보물 상자, 조각 수집, 짧은 대시, 목표 방향, 다리, 보스 게이트가 연결되었다. Tiled 구조 검증뿐 아니라 실제 `ground`·`paths`·`water`·`decor` tile layer를 Phaser가 렌더링하며, 수집 도감은 후속이다.

- NPC 2명과 그림 중심 말풍선
- `NPC 만나기 → 조각 찾기 → 다리 해제 → 보스` 퀘스트
- 상자 열기, 짧은 대시, 퀘스트 방향 표시
- 유아는 그림·조작·짧은 음성 안내 중심
- 숫자 숲 전용 수집 도감
- 16px 원본을 nearest-neighbor 2배 변환하는 32px Tiled JSON 제작 파이프라인

승인 게이트 A:

- 숫자 숲 10분 완주 플레이 영상과 실제 휴대폰 조작 검토
- 유아·초등 대표 프로필 각 1회 사용자 검토

## Phase 3 — 단어섬

현재 상태: **플레이 가능한 1차 맵 완료**. 독립 밤바다 배경, 사서·조개시인 NPC, 글자 룬 순서 수집, 단어 문, 단어 먹보 미믹과 국어 목표 문제가 연결되었다.

- 해변·마을·동굴 CC0 맵
- 글자 룬 수집, 단어 조합 문, 맞춤법 수호자
- 유아: 그림과 낱말
- 초등: 어휘·맞춤법·문장
- Stage 2 전용 퀘스트·보스·보상

완료 기준:

- Stage 1 재도전으로 Stage 3가 열리지 않음
- Stage 2를 실제로 클리어해야 Stage 3 해금

## Phase 4 — 이야기 성

현재 상태: **플레이 가능한 1차 맵 완료**. 독립 성 폐허 배경, 기록관·증언기사 NPC, 처음·가운데·끝 순서 수집, 기억의 도개교, 논리 장갑 수호자와 주장·근거 문제가 연결되었다.

- 성·도서관·비밀 통로 맵
- 이야기 조각 순서 맞추기
- NPC 증언을 모아 독해 문제 해결
- 문장 구성·중심 내용·추론 보스
- Stage 3 전용 엔딩과 탐험 도감

승인 게이트 B:

- 3개 월드 전체 흐름과 학년별 콘텐츠 표 검토
- 아동 친화 문구·난이도·보상 검수

## Phase 5 — 캐릭터와 인벤토리

- 능력치 과금 없는 외형 꾸미기
- 퀘스트·협동으로만 얻는 코스튬
- 수집품 상세 보기와 획득 장소
- 장비 비교 대신 발견·협력 기록
- 캐릭터 애니메이션, 감정 표현, 안전한 이모트

제외:

- 랜덤 뽑기
- 확률형 아이템
- 아이 사이의 유료 아이템 거래
- 학습 능력치를 결제와 연결하는 구조
- 구독, 광고, 유료 스테이지, 유료 부활
- 후원자를 위한 게임 내 우위·전용 학습 콘텐츠·아이 대상 후원 유도

## Phase 6 — 온라인 공동 탐험

- 친구 위치 보간
- 공동 스위치·두 명이 함께 여는 문
- 도움 신호·정해진 이모트
- 60초 재접속 보호
- 퀘스트 완료 저빈도 이벤트 동기화
- 서버 권위형 보상 검증

제외:

- 공개 랜덤 매칭
- 자유 채팅과 음성 채팅
- 위치 공유
- 공개 프로필·공개 랭킹

승인 게이트 C:

- 실제 휴대폰 2대와 Google 계정 2개로 공동 탐험
- 연결 끊김·앱 전환·재접속 검증
- Firestore 비용과 이벤트 빈도 검토

## Phase 7 — 보호자와 학습 데이터

- 개념별 시도·힌트·설명·협동 기록
- 주간 성장 이야기
- 점수 경쟁 없는 학습 리포트
- 자녀 데이터 내려받기·삭제
- 보존 기간과 개인정보 최소 수집 정책
- 관리자용 콘텐츠 검수 화면

## Phase 8 — 콘텐츠 제작 시스템

- 맵·NPC·퀘스트·문제 JSON 스키마
- Tiled 맵 검증기
- 중복 ID·막힌 포털·잘못된 스폰 자동 검사
- AI 문제 생성은 초안만 만들고 보호자/운영자 검수 후 게시
- 스테이지 추가 매뉴얼과 CC0 라이선스 자동 목록

## Phase 9 — 출시 준비

- 저가 Android, iPhone Safari, iPad/Android 태블릿, PC Chrome/Edge
- 20분 플레이 메모리·발열·배터리 검사
- Slow 4G 첫 로딩과 동적 Phaser 청크 검사
- WebGL 실패·context loss 복구
- 200% 확대, 키보드 완주, reduced-motion
- Firebase Java 21 Emulator 규칙 검증
- 보안 스캔과 개인정보 검토
- 장애 모니터링과 롤백 절차

최종 출시 승인 게이트:

- 3개 월드 대표 콘텐츠 완주
- 실제 두 계정 온라인 E2E
- 프로덕션 보안 규칙 검증
- 실제 기기 성능 기준 통과
- 개인정보·이용 안내 검토
- 배포는 별도 명시 승인 후에만 실행

## KPI

- 첫 탐험 시작률과 Stage 1 완주율
- 조작 설명 없이 첫 조각을 얻는 비율
- 포털 도착까지 걸린 시간
- 힌트 사용 후 성공률
- 친구 협동 완료율과 재접속 성공률
- 7일·30일 재방문율
- 학년별 중도 이탈 구간
- 실제 기기 FPS, 첫 인터랙션 시간, 오류율

## 현재 승인 범위

Phase 1 안정화와 Phase 2 숫자 숲 완성이 승인되었다. 교육과정 기반 주별 목표·진단·훈련장 기반도 함께 구현 중이다.

Phase 3 단어섬과 Phase 4 이야기 성은 데이터/진입 기반만 준비되었고, 독립 이동 맵·NPC·퀘스트는 아직 구현되지 않았다. 온라인 공동 탐험, 프로덕션 배포, 보안 규칙 배포는 각각 별도 승인이 필요하다.
